## 🥷 About

Shinobi Quest (SQ) is a Python RPG where you step into the life of a shinobi.

Choose your village, manage your resources, fight dangerous enemies, earn rewards, and become stronger as you progress.

Featuring a Rich-powered terminal interface, dynamic battle logs, health bars, inventory management, and turn-based combat, Shinobi Quest brings an RPG experience directly to your terminal.

**Your survival depends on your strategy.**

## ✨ Features

- ⚔️ **Turn-Based Combat** — Fight enemies using attacks, kunai, and strategic decisions.
- 👹 **Multiple Enemies** — Face different enemy types with distinct combat behavior.
- ❤️ **Character Stats** — Monitor HP, Chakra, XP, and Ryo.
- 🎯 **Critical Hits** — Deal increased damage with critical attacks.
- 🎒 **Inventory System** — Manage your items and consumables.
- 🏪 **Shop System** — Purchase supplies using earned Ryo.
- 🏯 **Village Selection** — Choose your starting village.
- 💾 **Save & Load** — Save your progress and continue your adventure.
- 🎨 **Rich Terminal UI** — Interactive layouts, status bars, and battle logs.
- 📈 **Level Progression** — Earn experience and grow stronger.

## ⚔️ Combat

Every battle requires strategy.

Choose your actions carefully, manage your resources, and adapt to your opponent's behavior.

| Action | Effect |
|:---|:---|
| Attack | Deals 10 base damage |
| Critical Hit | Deals 25 damage |
| Kunai | Deals 20 damage and consumes one kunai |
| Run | Attempts to escape |

Critical hits have a 5% chance of occurring during normal attacks.

Enemies can attack and heal, so careless decisions can cost you the battle.

## 🚀 Installation

### Requirements

- Python 3.x
- Git
- A compatible terminal

### 1. Clone the Repository

```bash
git clone https://github.com/Sejitz/Shinobiquest-.git
```

### 2. Enter the Directory

```bash
cd Shinobiquest-
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch the Game

```bash
python main.py
```

Start a new game or load your existing progress and begin your shinobi journey.
